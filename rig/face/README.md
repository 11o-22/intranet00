# 얼굴 파츠 (3배율 · 2400×2400)

쿼터뷰에 넣을 캐릭터 얼굴. `rig/body/머리.png` 와 같은 자리 · 같은 크기 캔버스라 그대로 겹치면 된다.

- `face/<이름>/` — 눈 · 눈썹 낱장. `오` = 오른쪽(먼 눈) · `왼` = 왼쪽(가까운 눈)
  - 흰자위 · 눈동자 · 속눈썹 아래 · 눈꺼풀 · 감긴 눈 · 눈썹
  - 몇몇은 더 있음: 고영은 `눈꺼풀(눈 감기 전용)` · 곽제강 `안경` · 백사헌 `안대` · 호유원 `눈동자 기본/특수` · `감은 눈`
- `mouth/` — 입 낱장. **입은 모든 캐릭터가 `기본 입` 하나로 통일** (2026-11-22)
- `hair/<이름>.png` — 머리카락 (같은 날 3배율로 교체 · 장허운 `장허운.png` 새로 들어옴)

겹치는 차례 (뒤 → 앞): 머리 → 입 → [흰자위 → 눈동자 → 속눈썹 아래 → 눈꺼풀] (감으면 이 넷 대신 감긴 눈) → 눈썹 → 머리카락
