# 약초 그림 (약초 채집용 · 2026-11-23)

아직 쓰는 코드 없음 — 그림만 모아 둠.

- `일반/01.png` ~ `15.png` — 검은 바탕 그림 한 장(5 × 3)에서 한 포기씩 잘라 투명 바탕으로
  - 가장자리 한 줄은 검은 바탕과 섞인 색을 풀어 반투명 · 흰 꽃 둘레 옅은 빛은 반투명으로 남김
  - 잎 사이로 보이던 검은 바탕은 비움
- `특별/01.png` ~ `05.png` — 투명 바탕 그림 한 장의 다섯 포기 (위 왼쪽부터 셋 → 아래 둘 · 빛 번짐 · 방울 · 반짝이 그대로)
- `목록.json` — 파일마다 원래 그림의 줄 · 칸(일반) 또는 차례(특별), 크기, 원래 그림 안의 자리
